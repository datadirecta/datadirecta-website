# Data Directa

Landing page for Data Directa, a subscription service that provides clean, structured datasets to agencies and firms.

Static site (HTML, CSS and a little JavaScript), hosted on GitHub Pages at https://datadirecta.co.

- `index.html`: home page
- `contact.html`: data request form (submissions handled by Formspree)
- `styles.css`, `marquee.js`: styling and the scrolling banners
- `images/`: site photos and logo
